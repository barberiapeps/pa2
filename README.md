# PA2 — My Chemical Romance (proyecto académico)

Sitio estático de 4 páginas hecho para el Proceso de Aprendizaje 2 del curso
Diseño y Desarrollo Web. Tema libre elegido: página de fan/banda sobre
My Chemical Romance.

## Páginas

- `index.html` — portada con fondo, título, slogan y menú.
- `blog.html` — cabecera fija, artículo sobre el álbum *The Black Parade*.
- `galeria.html` — galería de 6 imágenes con Flexbox y efecto hover.
- `videos.html` — dos videos oficiales de YouTube embebidos (responsivos).

## Notas

- Las imágenes de `img/` (hero, galería, portada del blog, avatar) son
  generadas, no fotos reales de la banda — evita cualquier tema de
  derechos de autor sobre fotografía oficial/prensa.
- El avatar del "autor" (`img/avatar.jpg`) es un placeholder — reemplázalo
  por tu propia foto antes de entregar, la consigna pide la foto real del
  alumno.
- No se incluye audio con derechos de autor; la etiqueta `<audio>` queda
  comentada en `index.html` lista para usar si se agrega una fuente propia.
